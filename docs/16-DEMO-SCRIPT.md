# Five Minute Assessment Demo Script

This script is a recording aid. It does not claim live integrations are already configured.

| Time | Segment | Show |
| --- | --- | --- |
| 0:00–0:30 | Overview | Architecture diagram and three task boundaries |
| 0:30–2:30 | Task 1 | Make scenario run, Airtable record, generated Google Doc, and Slack digest; show errors/retries if safe |
| 2:30–3:30 | Task 2 | Run URL or keyword mode, inspect `output.csv`, and show optional Google Sheets append |
| 3:30–4:30 | Task 3 | Send sample JSON through webhook and show the private Slack message |
| 4:30–5:00 | Code | Show configuration, tests, and README setup |

Before recording, replace the unconfigured workflow specifications with live Make scenarios and use test data only. Hide API keys, webhook URLs, contact details, and workspace identifiers. Capture the recording using the user's Loom account and add the approved share link to the submission README.
