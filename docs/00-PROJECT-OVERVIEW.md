# Project Overview

OpsLabs Developer Assessment demonstrates three related automations: contact enrichment and reporting, YouTube metadata collection, and Slack delivery from JSON. The repository supplies runnable local Python components and tenant-neutral Make workflow specifications. Live Google, Airtable, Slack, OpenAI, and Make account setup remains operator-owned.

## Outcomes

- Create and enrich synthetic contacts, document each company summary, and report daily.
- Collect video title, channel, description, publication date, view count, and URL to CSV and optionally Google Sheets.
- Validate weekly metrics and deliver a formatted message to a private Slack channel.
- Provide setup, operational, and change documentation suitable for a handoff.
